# 首次设置

新建或首次打开工作区后，LitNexus 会按三个独立步骤收集初始配置。三个步骤都可以稍后在「配置」页调整；选择「跳过」不会影响下载、合并、查看或导出，只会让需要模型服务的翻译和分类暂不运行。

## 1. 检索范围 { #retrieval }

填写期刊清单与 Europe PMC 关键词检索式。两者都是逐行输入，`#` 开头的行可作为注释。可以先保留示例、删空其中一项，或稍后再修改。

## 2. 筛选问题 { #questions }

首次默认提供一个示例问题。每个问题由 AI 独立回答「是 / 否」并给出理由；问题昵称与问题内容均为必填。可以保留一个、移除为零个，或按研究方向添加任意多个。一个问题的语义发生变化时，应在「配置」页新建并归档旧问题，而不是直接改写已有答案对应的问题。

对于已经建立数据库的工作区，首次向导不会覆盖现有问题定义或答案；请改到「配置」页管理。

## 3. 模型服务 { #ai }

模型服务是具名的 OpenAI 兼容接口配置，包含服务名称、Base URL、模型、API Key 与可选额外请求参数。首次设置同样可以添加、编辑或删除多个服务，并选择其中一个作为当前服务；翻译与分类在一次运行中只使用当前选中的服务。

可以暂不配置模型服务，之后再到「配置」页添加。API Key 保存在工作区的 `litnexus.toml` 中；分享或上传工作区前请先移除敏感信息。
