# 使用：运行

本页介绍 Mac 的完整流水线；Windows Preview 尚未实现运行页。

## 运行前准备

1. 打开工作区，在「配置 → 检索」中填写期刊或关键词检索式，至少有一条有效条目。
2. 如需翻译或分类，在「AI 与翻译」中选择当前模型服务并测试连接；在「分类」中检查启用的问题和生效范围。
3. 到「运行」页设定最近天数。新项目默认 14 天，修改后自动保存为本项目以后的默认值。

没有模型服务时，可先从更多操作里单独执行下载和合并。模型调用可能产生服务商费用。

## 开始一轮

选择「开始运行」，阅读运行前确认中的范围和 AI 待办，再确认执行。如果曾关闭询问，可通过更多操作中的「恢复运行前询问」重新开启。

| 步骤 | 完成后得到什么 |
|---|---|
| 下载 | 工作区 `downloads/` 中的原始 JSONL 文件 |
| 合并 | 去重写入数据库；处理完成的文件移入 `downloads/_merged/` |
| 翻译 | 缺少的译文，使用当前模型服务 |
| 分类 | 启用问题的 AI 答案与理由，按问题生效范围处理 |

「执行路径」显示状态、数量、耗时与警告。「运行记录」显示本轮摘要，技术详情用于排查失败。完成后到[数据页](data.md)导出 CSV；人工复筛导回也在那里单独进行。

## 中止与继续

点击「中止」后，等待安全检查点结束当前工作。已写入的结果保留，界面恢复空闲后再运行所需步骤。合并只处理尚未合并的文件，翻译和分类继续处理未完成记录；重新下载仍会访问 Europe PMC，不是恢复到某一网络分页的断点。

## 出错时怎么处理

| 现象 | 检查与恢复 |
|---|---|
| 下载失败或命中为零 | 检查网络、时间窗和检索式。先在 Europe PMC 验证检索式，再单独重试下载。遇到限流可增大「检索」中的分页间隔。 |
| 下载后库内数量没增加 | 确认合并步骤已完成；重复文章会跳过。检查合并记录是否报告缺少文章 ID 或文件错误。 |
| 翻译或分类失败 | 检查当前服务的地址、模型、密钥和余额，测试连接后重试该步。不要通过清空数据库来重试 AI。 |
| 分类没有待办 | 检查问题是否启用、是否归档，以及是否仅作用于以后新文章；历史补答需在配置中显式开启。 |
| 需要反馈错误 | 复制运行诊断并附上失败步骤；分享前检查是否含敏感内容，不要附带含 API Key 的项目配置。 |

检索配置见[配置指南](settings.md)，数据保护规则见[流水线](../reference/pipeline.md)。
