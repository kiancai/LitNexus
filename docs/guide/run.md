# 使用：运行

**用途**：按顺序执行下载、合并、翻译与分类，或从更多操作中单独运行某一步。

1. 设定抓取范围和时间窗口。新项目默认抓取最近 14 天；修改时间窗口后会自动保存为当前项目的默认值，以后运行及重新打开项目时继续使用，直到再次修改。
2. 选择“开始运行”。涉及 AI 的翻译和分类会在首次运行前确认，避免意外消耗额度。
3. 在“执行路径”查看每一步的状态、数量、耗时与警告。
4. 在“运行记录”查看本次运行的摘要；需要排障时再展开技术详情或复制诊断。

下载只产生原始文件，合并才会写入数据库；翻译和分类会调用当前项目选定的模型服务（可在[配置](settings.md)中切换）。中止会在安全检查点生效，已完成的工作会保留。
