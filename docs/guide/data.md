# 使用：数据

本页的完整流程以 Mac 为准。Windows Preview 已有 CSV 导出和复筛导回，整库维护尚未完整对齐。

## 查看状态与导出 CSV

1. 查看总文章数、待复筛、纳入和排除数量。这些是人工复筛状态，不等同于 AI 分类结果。
2. 在「导出 CSV」选择范围：全部、待复筛、纳入或排除。
3. 展开「选择导出列」，勾选阅读需要的字段。问题答案列由「配置 → 分类」中各问题的导出开关控制。
4. 点击「导出 CSV」，再点击「打开导出目录」查看工作区 `exports/` 下的文件。范围和列选择会记住为下次默认值。

`epmc_id`、`include`、`tags` 始终保留。只改 `include`（`yes` / `no`）和可选 `tags`；标题、摘要、译文和 AI 答案供阅读使用，不会随复筛 CSV 写回。

## 导回人工复筛

1. 选择「导入复筛结果」并打开编辑后的 CSV。
2. 查看预检报告。缺 ID、重复 ID 或非法值需先修复；未匹配文章和覆盖冲突也会列出。
3. 默认只填补空标注；确实需要替换旧标注时，显式开启「允许覆盖已有人工标注」，重新核对报告。
4. 点击「确认导入」。存在阻断错误时不能写入；有可写变更时会先自动备份。完成后查看更新数量。

留空表示本次不修改，不能用空白清除原有标注。完整格式和示例见[人工复筛与 CSV 导入](manual-review.md)。

## 备份与导入数据库

在数据库维护区域选择「导出数据库（备份）」，保存独立的 `.db` 快照。它是数据库备份；若需保存模型服务、检索配置和原始下载文件，还应在退出应用后备份整个工作区。

导入已有备份或其他项目的数据库：

1. 先确认当前项目正确，并保留一份当前数据库的独立备份。
2. 选择「导入数据库（跳过已有）」，打开源 `.db` 文件。
3. 若出现问题对齐界面，为源问题选择映射到当前问题、新建问题或跳过。不要仅因 ID 相同就当成同一个问题。
4. 确认导入并查看新增、跳过和备份提示。导入前会自动备份，默认保留当前已有文章。
5. 如只需补全当前文章的空字段，使用「高级导入：仅填补空缺字段…」。

导入是合并，不会把现有非空字段还原到旧快照。若要查看或取回完整旧快照，可新建独立工作区、导入备份并核对问题映射和数量，保留当前项目以供比较。

## 清空文章数据

1. 先导出独立备份，确认选择的是要清空的项目。
2. 展开「清空数据库」，点击同名按钮。
3. 阅读提示，输入完整项目名后确认。

此操作清除文章及其翻译、分类与复筛数据，保留配置和列结构；执行前会自动备份。没有一键撤销，请核实备份后再操作。
