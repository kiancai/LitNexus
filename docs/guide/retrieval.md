# 检索式与筛选问题生成指南

首次设置时，期刊列表、关键词检索式、筛选问题都可以用 AI 帮你生成。模型服务属于第三步，可跳过，也可以保存多个服务；请见[首次设置](setup.md)。
把下面的提示词复制到任意 AI 助手，替换其中的占位内容，即可得到适合你研究领域的版本，再贴回 app。

格式约定：

- 期刊：每行一个，名称需与 [Europe PMC](https://europepmc.org/) 中的名称完全一致；`#` 开头为注释，空行忽略。
- 关键词：每行一个 Europe PMC 检索式，支持布尔语法（`AND` / `OR` / `NOT`）与引号短语；`#` 开头为注释。
- 筛选问题：每个问题让 AI 对文章回答「是 / 否」并给出理由，文本应清晰、无歧义。

## 期刊列表 { #journals }

把下面这段发给 AI，替换 `{{你的研究领域}}`：

```text
我的研究领域是：{{你的研究领域}}。
请列出 5–10 个该领域最权威、最相关的期刊名，用于在 Europe PMC 按期刊抓取文献。
只输出期刊名，每行一个，不要编号、不要解释。
```

## 关键词检索式 { #keywords }

```text
我的研究领域是：{{你的研究领域}}。
请生成 3–5 条 Europe PMC 检索式，覆盖该领域的核心主题与交叉方向。
要求：使用布尔语法（AND/OR/NOT），短语用双引号包裹；每条一行，不要编号或解释。
```

## 筛选问题 { #questions }

```text
我的研究目的是从文献中筛选出与「{{你的筛选目标}}」相关的文章。
请按需要设计一个或多个筛选问题；也可以只给出一个足以判断的核心问题。每个问题让 AI 阅读文章标题与摘要后回答「是」或「否」，并附简短理由。
要求：问题文本清晰、可独立判断。每个问题分别输出「昵称」和「问题文本」，不要把多个判断条件混成无法独立回答的一题。
```

---

首次设置默认提供一个示例问题；你可以移除它、添加任意多个问题，或先不设置问题。之后仍可在「配置」页随时管理。已有文章产生答案后，语义变更应新建问题并归档旧问题，而非直接改写旧问题。模型服务不需要在此生成提示词：它在第三步单独配置，支持多个具名服务。
