# 使用：配置

**用途**：管理项目外观、检索列表、模型服务、翻译与分类参数、项目位置与高级数据结构。

- 外观模式只保存在当前设备；项目强调色写入 `litnexus.toml`，可随项目迁移。
- 期刊与关键词检索式编辑器按逻辑行显示行号；长内容发生视觉折行时不会增加编号。
- “检索”中的下载请求参数只控制 Europe PMC 分页：每页文献数有效范围为 1–1,000，通常建议 100–1,000；分页间隔默认 0.5 秒，通常建议 0.2–1 秒，遇到限流或网络不稳定时可增大。下载时间窗口只在“运行”页设置，并自动记作当前项目的以后默认值。
- 模型服务、分类问题、期刊清单与关键词检索式都会自动保存到项目配置；新项目以 `litnexus.toml` 为唯一主配置源。
- 模型服务可保存多个，但任一时刻只有一个「当前服务」；翻译与分类均使用它。删除当前服务后会自动选中剩余的第一个服务；若没有服务，AI 操作会提示先配置。
- CSV 导出的范围和列只在“数据”页调整，并会自动记住为下次默认值；配置页不再重复放置导出设置。
- `include`、`tags` 是固定的复筛列。额外人工列属于“项目 → 数据结构（高级）”，不改变复筛 CSV 只写入 `include` / `tags` 的契约。
- 新增问题时，应明确选择只用于未来新文章，还是为历史文章补答；后者会消耗额外 AI 额度。
- 修改分类问题文本前，请阅读确认选项。语义变化时应新建版本并归档旧问题，不能把已有答案直接解释为新问题的答案；归档问题默认不进入以后的分类与当前统计。
- API Key 位于项目配置中。共享或上传项目目录前，应先移除敏感信息。
