# 使用：配置

**用途**：管理项目外观、检索列表、模型服务、翻译与分类参数、项目位置与高级数据结构。

- 外观模式只保存在当前设备；项目强调色写入 `litnexus.toml`，可随项目迁移。
- 期刊与关键词检索式编辑器按逻辑行显示行号；长内容发生视觉折行时不会增加编号。
- “检索”中的下载请求参数只控制 Europe PMC 分页：每页文献数有效范围为 1–1,000，通常建议 100–1,000；分页间隔默认 0.5 秒，通常建议 0.2–1 秒，遇到限流或网络不稳定时可增大。下载时间窗口只在“运行”页设置，并自动记作当前项目的以后默认值。
- 模型服务、分类问题、期刊清单与关键词检索式都会自动保存到项目配置；新项目以 `litnexus.toml` 为唯一主配置源。
- 模型服务可保存多个，但任一时刻只有一个「当前服务」；翻译与分类均使用它。删除当前服务后会自动选中剩余的第一个服务；若没有服务，AI 操作会提示先配置。
- CSV 导出的范围和列只在“数据”页调整，并会自动记住为下次默认值；配置页不再重复放置导出设置。
- `include`、`tags` 是固定的复筛列。额外人工列属于“项目 → 数据结构（高级）”，不改变复筛 CSV 只写入 `include` / `tags` 的契约。
- 新增问题时，应明确选择只用于未来新文章，还是为历史文章补答；后者会消耗额外 AI 额度。
- 修改分类问题文本前，请阅读确认选项。语义变化时应新建版本并归档旧问题，不能把已有答案直接解释为新问题的答案；归档问题默认不进入以后的分类与当前统计。
- API Key 位于项目配置中。共享或上传项目目录前，应先移除敏感信息。

## 编辑检索范围

打开「配置 → 检索」，逐行输入期刊名与关键词检索式。空行和以 `#` 开头的行不参与下载。更改列表影响后续下载，不删除已有文章。下载最近天数在「运行」页调整；本页调整每页数量和分页间隔。生成示例见[检索式指南](retrieval.md)。

## 添加或切换模型服务

1. 打开「AI 与翻译」，选择「新增服务」。
2. 填写服务名、接口地址、模型名称、API Key；服务商需要额外参数时再填写 JSON。
3. 选择该服务作为当前服务，点击「测试连接」检查接口。
4. 核对翻译选项，再到运行页执行。保存多个服务不会让一次运行同时调用多个服务。

## 管理筛选问题

1. 打开「分类」，选择「添加问题」，填写昵称和问题内容。
2. 选择生效范围。默认只处理以后新入库文章；选择历史补答后，已有文章会进入下次分类待办，不会立即调用 AI。
3. 按需调整 AI 启用和导出开关。编辑昵称或问题文本时，使用卡片中的保存按钮提交草稿。
4. 已有答案的问题发生语义变化时，优先选择「新建为新问题」；仅修正措辞才考虑保留旧答案。就地修改并清空旧答案会丢弃该问题已有结果。
5. 不再使用的问题选择「归档」。需要时可恢复；彻底删除位于高级维护流程，会先备份并要求确认问题 ID。

问题和检索式的完整版本化数据库仍属于后续规划，见[数据库生命周期](../reference/database.md#question-query-lifecycle)。

## 项目与高级数据结构

在「项目」中打开项目目录或切换项目。额外人工字段在「数据结构（高级）」中管理；通常保留默认字段即可。额外字段不扩展复筛 CSV 的写回范围，仍只回写 `include` 与 `tags`。修改结构前建议先在[数据页](data.md)导出数据库备份。

本页以 Mac 为准；Windows Preview 只提供基础配置，尚未具备全部上述功能。
